## Your Intelligent Virtual Healthcare Companion

AAROGYA AI is a premium healthcare web application that demonstrates the power of Agentic AI in assisting users with symptom analysis, intelligent medical conversations, personalized recommendations, and secure health record management.

The project showcases multiple AI agents collaborating to understand user symptoms, ask relevant follow-up questions, generate medical summaries, assess urgency levels, and provide healthcare guidance.

---

# Project Overview

AAROGYA AI is designed to improve access to preliminary healthcare assistance by combining multiple specialized AI agents into a single intelligent workflow.

Users can:

- Register and Login
- Store their medical history
- Upload medical reports
- Chat with an AI healthcare assistant
- Receive symptom analysis
- Get personalized healthcare recommendations
